# 本地双币账本

供个人在这台电脑使用的中文账本：人民币与新币钱包、消费与收入、实际换汇、历史汇率折算、照片、分类、月度统计、备份恢复。Python 3.14 标准库实现，无第三方安装步骤。

## 打开与关闭

Windows 用户可运行项目中的 `创建桌面快捷方式.ps1`，生成桌面的 **记账** 快捷方式及本地图标。一键启动服务并打开默认浏览器；服务已运行时会直接打开同一本账，启动过程中会等待页面就绪。服务在后台运行，关闭浏览器不会停止服务，重启电脑后再次双击即可。快捷方式使用项目中的 `desktop_launcher.py`，请保留项目文件夹的位置。

桌面入口不会创建开机自启动。需要查看启动错误时，仍可使用下面的命令窗口入口；桌面启动日志位于 `private/work/desktop-startup-*.log`，不记录账目内容。

双击 **启动记账.bat**。网页地址默认是 `http://127.0.0.1:8765`。保持启动窗口运行，关闭窗口或按 Ctrl+C 停止网站。数据保存在当前项目的 `private/`，重启后保留。

命令行：
```powershell
python run_ledger.py
python run_ledger.py --no-browser
python run_ledger.py --port 8766
```
离线时仍能记账和查看。`--offline` 可完全禁用汇率联网，待下次正常启动再补齐。一个数据目录同时只允许运行一个服务器。`--data-dir` 只能选择当前项目 `private/` 内的目录。

## 分享一份独立空账本

运行 `python 制作分享版.py`，会在 `dist/` 生成可发送的 ZIP。打包使用固定文件白名单，不包含 `private/`、照片、备份、导出、测试数据或开发审查记录。接收者解压后双击自己的“启动记账.bat”，其数据会保存在他电脑上的独立 `private/` 中。

## 首次使用：填写钱包

可以先记录消费和收入；如果尚未确认余额，钱包会显示“待初始化”，但账目和月度统计仍会保存。之后再分别输入人民币和新币的**真实余额**以及余额截至日期。月度基准一般选上个月最后一天，表示该日结束时的实际余额。不生成任何示例账目或默认余额。

钱包余额 = 最近一次确认的实际余额 + 截止日期之后的收入 − 截止日期之后的支出，再加减实际换汇。

每笔账目保存成功后，页面立即读取并显示最新钱包余额；保存按钮下方会显示本次扣款或入账及新余额。钱包不等待周末或月底结算，也不依靠定时刷新。截止日期仅用于区分已包含在初始余额中的历史账目。

**补记截止日以前的消费，会更新消费所属月份统计，但不会再次扣款。** 例如你已填写 8 月 31 日实际余额，9 月补记 8 月 10 日消费时，8 月报表更新，当前钱包不重复扣款。月份不会自动清空账目或重置余额。余额校正是新的实际余额基准，旧记录保留可查。

## 记录与修改

每笔记录需要消费日期、币种、金额、自填名称与分类；备注和照片可选。名称可写“鱼虾面”，类别选“三餐”。网站中可新增、编辑、删除，也可以在当前 Codex 对话里告诉我明确日期、币种和消费内容。

类别管理支持删除类别。确认后，该类别从管理列表和新建账目的选项中移除；历史账目、原分类名称、统计和钱包余额保持不变。查找历史记录时仍可选择标注“已删除”的原类别，编辑旧账也可保留原分类。重新添加同名类别会创建一个新类别，不改变旧账。删除前沿用账本的自动备份保护。

对话写入通过本机接口执行，成功后给记录编号和回执；缺少日期、币种或无法确定类别时先补问。类似记录会提示确认，避免一条消息重试后重复记账。对话本身是你正在使用的 Codex 服务；原始账本文件不会因此整体上传。

换汇填写实际转出的币种与金额，以及实际收到的另一币种金额。换汇影响两个钱包，但不计为消费或收入。同币种的本人账户转账可保存为内部转账，只保留审计记录，不改变钱包余额或收支统计。余额允许为负，会提示检查。

照片可选，每笔最多 20 张，支持本地 JPEG、PNG、WebP，单张不超过 8 MiB。选择文件时可按 Ctrl / Shift 多选，也可分次追加；保存前可预览和逐张移除，编辑旧账时保留未移除的照片。照片在账目名称右侧横向排列，为约三个字宽、三个字高的小方形缩略图，较多时可横向滚动，点击查看原图。照片不发送外部识别服务。移除附件或删除账目不会自动销毁本地原图及历史备份中的照片。

收支记录按日期倒序分组，点击日期或星期右侧箭头可展开、收起当天明细。日期右侧按人民币、新币分别显示收入与支出，合计只包含当前筛选结果，不叠加参考折算金额；单笔新币账目仍保留消费日的人民币折算。

“查找记录”支持按原币金额精确筛选。金额填 6，币种选新币，就查找金额为 SGD 6.00 的账目；选人民币则查找 CNY 6.00，选全部币种则同时显示两者。输入金额后自动筛选，也可点击“应用筛选”。可与日期、类别、名称组合；不填写日期时沿用总览所选月份。清空金额或点击“清除筛选”可取消金额限制。导出的 CSV 沿用当前筛选条件。

## 汇率如何计算

- 人民币始终保持人民币，不转换为新币。
- 新币按**消费日期**折算人民币参考金额，采用十进制定点计算并四舍五入至分。折算只用于统计，不扣人民币钱包。
- 固定来源：Frankfurter v2 的 ECB 接口，源地址 `https://api.frankfurter.dev/v2/providers/ecb/rate/sgd/cny`。
- 首页“今日参考汇率”显示截至今天最新可用的 ECB SGD→CNY 报价及实际报价日期；休市日显示此前最近工作日。
- 首页月度收入、支出和分类统计按人民币、新币原币分别合计，不把新币汇总折算成人民币。
- 每一笔新币收支仍同时保存原始新币金额和按该笔发生日期计算的人民币参考金额；补录旧账不会使用补录当天汇率。
- 消费日期和实际报价日期分开显示。ECB 周末及 TARGET 休市日沿用此前最近工作日报价；普通工作日没有当天报价时保持待更新。
- 当天尚未公布、断网或响应异常时，原币账目正常保存，人民币金额显示待更新。启动网站或点击更新重试；已经确定的历史汇率不随今天报价变化。
- 月度收入、支出和分类统计分别显示人民币与新币原币合计。待折算笔数只表示个别新币记录的人民币参考金额尚未补齐；以界面选择月份为准，账目搜索筛选不会改变月度汇总的月份含义。

参考来源：[Frankfurter 文档](https://frankfurter.dev/)、[ECB 参考汇率说明](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)。这是参考折算，不代表银行卡、支付平台或换汇商的实际成交价。

## 本地保存、导出与恢复

GitHub 仓库只保存程序源码、使用说明、字体许可和虚构数据测试，不保存个人账本。`.gitignore` 默认忽略所有文件，仅允许明确列出的源码文件；新增源码需先检查内容再加入允许清单。请勿强制提交 `private/`、照片、备份、导出、报表、临时文件、本机配置或任何凭据。克隆仓库会得到一份独立空账本，不会下载或同步其他人的记账数据。

`private/` 包含数据库、照片、备份、导出、会话配置和工作文件。不要删除或上传这个目录。程序与数据都在同一台电脑上；本地文件不额外加密，因此应使用自己的 Windows 账户保管电脑。

- 启动时检查并生成当天的完整自动备份；跨日持续运行时，在当天首次业务写入前生成。自动备份保留最近 30 份；手动备份单独保留。
- 如果备份失败，保存会停止并显示具体的安全错误说明，账本不因该次保存而改变。启动窗口也会提示检查结果；修复原因后可重试保存，无需关闭备份保护。
- 备份包含数据库和照片；恢复前再备份当前状态。只恢复应用备份列表中的文件，先校验内容，再切换数据。
- CSV 适合查看和表格分析；它不包含照片和完整恢复信息，不能替代完整备份。
- 可自行将备份复制到自己的加密磁盘，防止电脑硬盘损坏。应用不会自动同步到任何云盘。

网页仅监听 `127.0.0.1`，不对局域网或公网发布；无广告、统计 SDK、远程字体、CDN。唯一主动外网请求是历史汇率，发送固定币种和日期，不发送金额、名称、照片、备注或钱包余额。

钱包余额、月度收支和汇率金额使用本地 Inter 字体，启用等高、等宽数字；金额数字采用 500 字重和略紧的字间距，币种使用独立的颜色与间距。钱包与收支金额显示千位分隔符，仅改变排版，不影响金额精度、账目或输入格式；窄卡片自适应字号，超长金额可横向滚动查看。字体随项目和分享包一起保存，离线可用，不需安装到 Windows。字体来自 [Inter 官方 v4.1](https://github.com/rsms/inter/tree/v4.1/docs/font-files)，文件为 `ledger_app/static/fonts/InterVariable.woff2`，遵循随附 `OFL.txt` 中的 SIL Open Font License 1.1。字体 SHA-256：`693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`。

C2C 是开发期间的只读代码审查连接，不是账本入口。`.c2cignore` 和 `.gitignore` 排除了所有私有数据。不要将真实消费放入源码、测试或审查报告。

## 对话结构化接口

网站启动后使用：
```powershell
python -m ledger_app.cli state --month 2026-08
python -m ledger_app.cli command --action entry.save --request-id UNIQUE-ID --file private/work/entry.json
```
先通过 state 取得实际分类 ID，再准备 JSON payload。payload 包含 `date`、`currency`、`amount`（字符串）、`kind`（expense/income）、`name`、`category_id`，可加 `note` 和 `photo_ids`（通过 `photo.save` 得到的照片 ID 数组）。编辑时省略照片字段会保留已有照片，传空数组则移除全部关联；旧的单张 `photo_id` 仍兼容。重试必须使用同一请求编号。错误返回 `ok:false`，不能当作成功。

本机 HTTP 端点及模块接口见 `CONTRACT.md`。CLI 自动建立同源会话、带上 CSRF 验证；不读取或打印会话密钥。不要直接修改 SQLite。

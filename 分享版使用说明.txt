双币账本（独立使用版）
======================

这是一份全新的空账本，不包含发送者的余额、账目、照片、备份或导出文件。
你的数据只保存在解压后的 private 文件夹中，与发送者的账本互不影响。

首次使用
--------
1. 将整个压缩包解压到自己的电脑，不要直接在压缩包里面运行。
2. 电脑需要安装 Python 3（此版本使用 Python 3.14 验证）。安装时勾选“Add Python to PATH”。
3. 双击“启动记账.bat”。
4. 浏览器会打开 http://127.0.0.1:8765/ 。使用期间保持黑色启动窗口开启。
5. 可以直接记录消费和收入；如果暂时不知道余额，钱包会显示“待初始化”，不影响记账。以后进入“钱包与余额”再分别填写人民币和新加坡元的实际余额及余额截止日期即可。

以后使用
--------
每次重启电脑后，再双击“启动记账.bat”。账本数据会从 private 文件夹自动读取。
关闭黑色启动窗口会停止网站，但不会删除数据。

隐私与备份
----------
网站只监听本机地址，不要把 private 文件夹、账本数据库、照片或备份发送给其他人。
“备份与导出”中的完整备份包含账本和照片，应像银行卡资料一样保管。
联网时，程序只向 Frankfurter/ECB 查询指定日期的新加坡元兑人民币参考汇率。

常见问题
--------
如果双击后提示找不到 python，请先安装 Python，并重新打开此文件夹。
如果提示端口被占用，通常表示账本已经启动；直接打开 http://127.0.0.1:8765/ 即可。

双币账本（独立使用版）
======================

这是一份全新的空账本，只包含程序，不包含发送者的余额、账目、照片或备份。
每个人在自己的电脑上运行，数据保存在各自项目的 private 文件夹中，互不影响。
不需要 Codex、记账账号或 API Key，也不会通过 GitHub 同步个人账目。

完整使用说明：
https://github.com/ZHX-ctrl/local-ledger#readme

一、首次启动
------------
1. 将整个压缩包完整解压到自己有读写权限的本地文件夹，不要在压缩包预览窗口里运行。
2. 安装 Python 3.14（当前验证版本），然后重新打开 PowerShell，运行 python --version 检查。
   官方下载：https://www.python.org/downloads/
   使用传统安装器时，如有 Add Python to PATH 选项，请勾选。
   新版 Python Install Manager 还需要安装实际 Python 运行时，详见官方说明：
   https://docs.python.org/3.14/using/windows.html
3. 找到同时包含 run_ledger.py、启动记账.bat、ledger_app 的那层项目目录。
4. 双击“启动记账.bat”，等待出现“本地账本已启动”。
5. 浏览器会打开 http://127.0.0.1:8765/ 。没有自动打开时，手动输入该地址。
6. 使用期间保持命令窗口运行。不要直接打开 static 目录中的 HTML 文件。

也可以在项目文件夹打开终端，执行：
python -X utf8 run_ledger.py

如果 python 不可用，但 py -3.14 可用，可以临时改用：
py -3.14 -X utf8 run_ledger.py

本精简分享包不包含桌面快捷方式脚本。需要桌面一键启动时，可下载 GitHub 完整源码，
按仓库使用说明创建快捷方式。

二、填写自己的余额
------------------
可以先记录收支，钱包显示“待初始化”不影响保存。
确认余额后，进入“钱包与余额”，分别选择人民币/新加坡元，填写自己的真实余额和截至日期。
截至日期表示当日 23:59 的实际余额，不要把现在余额随意写成昨天余额。

钱包 = 基准余额 + 截止日之后的收入 - 截止日之后的支出 + 实际换汇净变动。
发生日期早于或等于截止日的记录只更新历史统计，不重复扣款。
发生日期晚于截止日的收支，保存成功后立即更新相应币种钱包。
多次余额快照按截止日期最新者计算；同日以最后保存者为准。

三、日常记账
------------
进入“收支记录”或点击“＋ 新建记录”，选择收入/支出、实际发生日期、币种、金额、名称和类别。
新建账目默认新币；记人民币时请切换币种。收入和支出都填写正数金额。
等待保存成功提示，失败或待确认时不要当作已经记入。
可编辑、删除、按日期/类别/名称/原币金额查找记录。

每笔最多 20 张照片，支持 JPEG、PNG、WebP，单张不超过 8 MiB。
照片保存在本机；删除照片关联不等于删除原文件或历史备份中的照片。
新币账目按发生日期计算人民币参考金额，参考折算不会再扣人民币钱包。
汇率缺失时原币账目仍可保存，之后在“换汇记录”点击“更新待汇率”。

实际换汇需要先初始化两个钱包，填写真实转出和到账金额，不计收入/支出。
本人账户之间的同币种资金移动使用“内部转账”，不改变同币种合计钱包。

四、以后启动与备份
------------------
重启电脑后，再双击同一个“启动记账.bat”。
先保存完记录，再关闭命令窗口或按 Ctrl+C 停止服务；停止服务不会删除账目。
只关闭浏览器不会停止命令窗口中的服务。

进入“备份与导出”点击“立即创建备份”，完整备份保存在 private/backups/。
恢复会替换当前账本，不是合并记录。CSV 只用于表格分析，不能代替完整备份。
换电脑或更新程序前先备份并停止服务；迁移时把自己的整个 private 文件夹复制到新项目，
确认数据完整前保留旧文件。两份副本不会自动同步。

五、常见问题
------------
找不到 python：先确认 Python 运行时与命令配置正确，或用 py -3.14 命令启动。
网页打不开：确认服务窗口仍在运行，且浏览器使用窗口打印的地址。
端口被占用：先核对是否已有自己的账本在运行；若是其他程序或另一份账本，使用：
python -X utf8 run_ledger.py --port 8766
然后打开 http://127.0.0.1:8766/ 。不要随意关闭不认识的进程。

备份失败、账本未改变：读取具体错误，检查文件读写权限、磁盘空间、照片目录及安全软件拦截，
解决原因后重试。不要通过删除账本或关闭备份保护来绕过错误。
照片不支持：检查实际格式和大小；仅改扩展名不等于转换格式。
钱包不扣款：核对钱包是否初始化、发生日期是否晚于余额截止日。
找不到旧记录：检查总览月份和查找条件。

六、隐私
--------
private 文件夹、数据库、照片、完整备份、导出、日志都应由自己保管，不要上传 GitHub、Issue 或 PR。
程序只监听本机 127.0.0.1，不提供手机同步或公网多人访问。
程序主动联网仅用于 Frankfurter/ECB 汇率查询，发送币种和日期，不发送金额、名称、照片或余额。
完全离线时，可先停止已运行的服务，再执行 python -X utf8 run_ledger.py --offline。
界面“已同步”只表示浏览器已读取本机服务数据，不代表同步到云端。
